# --- Settings
Aspect Ratio
Auto
Stretch
The game's picture shape on the TV.
Letterbox Zoom
Fills a 16:9 TV with games that letterbox a 16:9 picture (Resident Evil 4).
Widescreen Hack
Renders a wider view in 4:3 games (may show glitches at the edges).
Crop to Aspect Ratio
Crops the picture to the chosen aspect ratio instead of adding black bars.
Internal Resolution
Native (480p)
Sharper pictures at higher settings; costs GPU time.
Frame Rate Limit
Unlimited
Auto (60/30)
Caps the frames shown per second. Auto: 60 while the game keeps up, an even 30 when it can't (steadier than a frame rate that bounces around).
V-Sync
Waits for the TV's refresh (no tearing).
FPS Counter
Frames and emulation speed in the corner.
Texture Filtering
Default
Smooth (linear)
Sharp (nearest)
How textures are smoothed.
Anisotropic Filtering
Sharper textures at an angle; costs GPU time.
Anti-Aliasing
Smoother edges; costs GPU time.
Disable Fog
Removes distance fog (some games use fog for effects).
Copy Filter
The game's own blur/deflicker filter on copies; Off is sharper.
EFB Copies
To Texture (fast)
To RAM (accurate)
Some effects need RAM copies; Texture is faster.
CPU Access to EFB
Needed by some games (lens flares, cursors); Off is faster.
Manual Texture Sampling
Exact texture sampling (fixes some videos, e.g. FIFA Street 2); slower.
GPU Texture Decoding
Decodes game textures on the GPU instead of the video thread (helps draw-heavy scenes).
Shader Compilation
Asynchronous
Hybrid Ubershaders
Synchronous
Asynchronous: no stutter, objects may appear a moment late. Hybrid Ubershaders: no stutter and nothing missing, costs GPU time. Synchronous: waits for each new shader.
Emulated CPU Clock
Auto lowers the clock only when the CPU is the limit.
Speed Features
Fast
Compatible
Compatible turns off the port's command-stream shortcuts if a game glitches or freezes.
Dual Core
Forced
Emulates the GPU on its own thread.
Vulkan Thread
Records graphics commands on a separate core.
Fast Disc Speed
Shorter loading pauses (rarely breaks a game).
Performance Graphs
Frame time and speed graphs on screen.
Language
The menus' language, and the games' own language where the GameCube or Wii has it. The menu restarts to change it.
Game Volume
Volume of the games' sound.
What is plugged into the Wii Remote. Wii Sports and similar games need None.
For games played with the Wii Remote held sideways (NSMB Wii, Mario Kart Wii).
Audio Buffer
Larger is smoother when a game runs below full speed; smaller has less delay.
All Diagnostics
Every switch below at once. Off: nothing is recorded while you play.
Performance Log
Speed, FPS and hitches every 2 seconds (boot-trace.log).
Freeze Reports
Where the emulator was stuck when a game freezes, stalls or starts slowly.
Emulator Log
Dolphin's own messages (dolphin.log).
Profiler
Records where the time goes (samples.log). Costs speed - only for diagnosing slow games.
